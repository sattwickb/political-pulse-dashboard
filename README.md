# Political Pulse Contributions Dashboard

A single self-contained HTML page tracking Political Pulse contributions by
centre, built from the monthly quadrant exports.

- `index.html` — the dashboard. No build step, no dependencies, no network calls.
- Published with GitHub Pages from the `main` branch, root folder.

## Updating it each month

Replace `index.html` with the newly generated file and push. GitHub Pages
redeploys within a minute or two.

## What the numbers mean

A joint story counts in full for every reporter and centre named on it, so
per-reporter figures add to more than the section total; centre totals count
each story once. Spelling variants of one byline are merged.

Quadrants: a story is high reach at 3,000 page views or more, and high
engagement at an average engaged time of 75 seconds or more.
A = high reach, high engagement. B = high reach, low engagement.
C = low reach, high engagement. D = low reach, low engagement.
